PipeGen Track A Architecture Stages

Stage 1: Formal Requirements

Specifies real-time edge constraints (<33.3ms, ≥30 FPS), target hardware (NVIDIA Jetson / GPU), 17-point pose kinematics, ADL discrimination logic (walking, sitting, bending vs falls), privacy-by-design face obfuscation, and actionable MQTT JSON events.

requirement.yaml • specification.json • requirements_doc.md

Stage 2: Hardware-Neutral Pipeline IR

Defines the end-to-end directed acyclic graph (DAG): VideoInputSource → StreamMux → Preprocessor → PrimaryPoseInference → MultiPersonTracker → FallKinematicsAnalytics → PrivacyPreservingFaceMasker → OSD → VideoSink & MQTTAlertSink.

pipeline.ir.yaml • pipeline.ir.json • pipeline_graph.md

Stage 3: AI Model & Keypoint Topology

YOLOv8n-Pose architecture: 3.29M parameters, 9.2 GFLOPs, 17 COCO keypoints. Exported to ONNX opset 17 with static/dynamic execution profiles and synthetic calibration dataset for INT8 PTQ.

yolov8n-pose.onnx • model_card.md • coco_keypoints.json

Stage 4: TensorRT Compiler & Performance Report

Compiles ONNX model into FP16 and INT8 TensorRT engines. Jetson Orin Nano benchmarks: FP16 achieves 88.5 FPS (11.3ms total latency); INT8 achieves 116.3 FPS (8.6ms total latency, 1.72x inference speedup, 0.9% mAP deviation).

deepstream_app_config.txt • performance_report.md • compile_tensorrt.sh

Stage 5: Edge Run & MQTT Actionable Dispatch

Executes live perception pipeline with multi-person tracking, debounced state machine (NORMAL → POTENTIAL FALL → FALL CONFIRMED), MQTT alert publishing to elderly_care/alerts/fall, and real-time visual analytics.

run_pipeline.py • fallback_runner.py • deepstream_pipeline.py • mqtt_alert_publisher.py
